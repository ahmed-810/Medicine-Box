# Medicine-Box 💊

صندوق دواء ذكي مبني على **Arduino Mega 2560** (العقل) و**Arduino Uno** (السيرفوهات)، بيفتح الخانة تلقائيًا في ميعاد كل جرعة، وينبّه المريض بالصوت والإضاءة، ويسجّل الجرعات المأخوذة والفائتة، ويتواصل مع تطبيق أندرويد عن طريق Bluetooth.

## المميزات

- حتى **4 جرعات يوميًا**، وقت كل جرعة قابل للتعديل (من الأزرار أو من التطبيق).
- **4 سيرفو**: كل خانة بتتفتح في ميعادها وتتقفل بعد تأكيد أخذ الجرعة (الجرعة n = الصندوق n).
- **إنذار** بـ Buzzer + LED لكل جرعة + LED حالة (أحمر/أخضر).
- **شاشة LCD 16x2** بتعرض الساعة والتاريخ وحالة الجرعة، وبتتعمل لها إعادة تهيئة كل دقيقة عشان لو اتلخبطت ترجع لوحدها.
- **ساعة RTC (DS1302)** بتكمل شغل بالبطارية حتى لو الكهرباء قطعت، وبتتضبط من التطبيق.
- **سجل أحداث** (آخر 40 حدث) محفوظ في EEPROM: جرعة مأخوذة / فائتة (بعد **ساعة** من ميعادها).
- **Bluetooth (HC-05)** للتحكم والمتابعة من التطبيق.
- **إشعارات** على الموبايل وقت كل جرعة (رقم الجرعة، رقم الصندوق، الوقت).
- الإعدادات بتتحفظ ومبتضيعش عند فصل الكهرباء.

## فكرة التصميم

السيرفوهات بتسحب تيار كبير وقت الحركة، ولو اتغذت من الأردوينو الأساسي بتحصل هبوطات في الجهد بتلخبط الشاشة وبتمسح ساعة الـ RTC. عشان كده:

- **Arduino Mega**: الشاشة، الساعة، البلوتوث، الأزرار، اللمبات، البازر، والمنطق كله.
- **Arduino Uno**: بيشغّل السيرفوهات بس، وبيستقبل الأوامر من الـ Mega على Serial.

## التوصيل

### Arduino Mega

| الوظيفة | Pins |
|---|---|
| أزرار التأكيد (1-4) | 2, 4, 7, 8 |
| LEDs الجرعات (1-4) | A0, A1, A2, A3 |
| Buzzer | 10 |
| LEDs الحالة | 11, 13 |
| زر الإعدادات | 12 |
| RTC DS1302 (DAT / CLK / RST) | 22 / 23 / 24 |
| LCD I2C (SDA / SCL) | 20 / 21 |
| HC-05 (Serial1) | TX1 = 18، RX1 = 19 |
| رابط الـ Uno (Serial2) | TX2 = 16 |

وصلة HC-05:

- `HC-05 TX` ← `RX1 (19)`
- `HC-05 RX` ← `TX1 (18)` **عن طريق مقسم جهد** (1K من البن، و2K للـ GND، والـ RX من النقطة اللي بينهم) لأن الـ Mega بيطلع 5 فولت والـ HC-05 بيستحمل 3.3 فولت على خط RX.

### Arduino Uno (السيرفوهات)

| الوظيفة | Pins |
|---|---|
| Servos (الخانات 1-4) | 3, 5, 6, 9 |
| استقبال الأوامر من الـ Mega | RX (pin 0) ← TX2 (pin 16) في الـ Mega |

**الباور:**

- السيرفوهات: الأحمر على 5V، والبني/الأسود على GND، مع كابستور 470–1000µF قريب منها.
- لو هتشغّل سيرفو واحد صغير بس، ممكن يشتغل من باور الـ Uno (شاحن موبايل 5V/2A). لو أكتر، استخدم مصدر 5V/3A خارجي للسيرفوهات.
- **GND مشترك**: لازم GND الـ Uno وGND الـ Mega (وسالب المصدر الخارجي لو موجود) يتوصلوا ببعض.
- الـ Mega على شاحن موبايل منفصل. وما تشغّلش الشاشة أو الـ HC-05 أو الـ RTC من باور الـ Uno.

## الإعدادات من الأزرار

اضغط زر الإعدادات (pin 12) لدخول الوضع، ثم:

- **B1**: رجوع للحقل السابق
- **B2**: زيادة (+)
- **B3**: نقصان (-)
- **B4**: الحقل التالي (وفي آخر حقل يحفظ ويخرج)

## أوامر Bluetooth

الإعدادات: 9600 baud، كل أمر في سطر منتهي بـ `\n`.

| الأمر | الوظيفة |
|---|---|
| `STATUS?` | حالة الصندوق |
| `HISTORY?` | سجل آخر 7 أيام |
| `DATE?` | قراءة ساعة الصندوق |
| `SETDATE,y,mo,d,h,mi,s` | ضبط التاريخ والوقت، مثال: `SETDATE,2026,11,15,18,05,30` |
| `SETCOUNT,n` | عدد الجرعات (1-4) |
| `SETTIME,index,hour,minute` | ضبط ميعاد جرعة |
| `CONFIRM,index` | تأكيد أخذ جرعة |
| `HELP` | قائمة الأوامر |

الردود: `STATUS,...` / `DATE,...` / `EVENT,DUE|TAKEN|MISSED,n` / `HISTORY,...` / `OK,...` / `ERR,...`

## تشغيل الأردوينو

1. ثبّت المكتبات من Library Manager.
2. **الـ Mega:** افتح `Medicine-Box.ino`، اختار اللوحة **Arduino Mega or Mega 2560** والبورت وارفع الكود.
3. **الـ Uno:** افتح `Servo-Uno/Servo-Uno.ino`، اختار **Arduino Uno** والبورت وارفع الكود. **افصل سلك pin 0 وقت الرفع** وارجعه بعدها.
4. اقرن الـ HC-05 مع الموبايل (الباسورد الافتراضي غالبًا `1234`).

> ⏰ الساعة بتتضبط تلقائيًا بوقت الموبايل أول ما التطبيق يتصل، وتقدر تضبطها في أي وقت من زرار **ضبط الساعة من الموبايل**. كمان لو الـ DS1302 فقدت الوقت (رجعت لسنة قبل 2024) بتتضبط على وقت تجميع الكود عند التشغيل. تأكد من تركيب بطارية CR2032 عشان الوقت ميرجعش بعد فصل الكهرباء.

## تطبيق الأندرويد

التطبيق مكتوب بـ Kotlin وJetpack Compose، وبيتبني تلقائيًا بـ GitHub Actions:

- الكود في `src/main`.
- كل ما تعمل Commit على `main`، GitHub بيبني ملف `MedicineBox.apk` ويرفعه في تاب **Releases**.
- التطبيق بيتصل بالـ HC-05 (Bluetooth Classic)، ويعرض الجرعات ويعدّل المواعيد ويعرض السجل، ويبعت إشعار وقت كل جرعة.
- بيضبط ساعة الصندوق تلقائيًا أول ما يتصل، وبيعرض ساعة الصندوق مع تحذير لو مختلفة عن الموبايل.
