# Medicine-Box 💊

صندوق دواء ذكي مبني على **Arduino Mega 2560**، بيفتح الخانة تلقائيًا في ميعاد كل جرعة، وينبّه المريض بالصوت والإضاءة، ويسجّل الجرعات المأخوذة والفائتة، ويتواصل مع تطبيق أندرويد عن طريق Bluetooth.

## المميزات

- حتى **4 جرعات يوميًا**، وقت كل جرعة قابل للتعديل (من الأزرار أو من التطبيق).
- **4 سيرفو**: كل خانة بتتفتح في ميعادها وتتقفل بعد تأكيد أخذ الجرعة (الجرعة n = الصندوق n).
- **إنذار** بـ Buzzer + LED لكل جرعة + LED حالة (أحمر/أخضر).
- **شاشة LCD 16x2** بتعرض الساعة والتاريخ وحالة الجرعة.
- **ساعة RTC (DS1302)** بتكمل شغل بالبطارية حتى لو الكهرباء قطعت.
- **سجل أحداث** (آخر 40 حدث) محفوظ في EEPROM: جرعة مأخوذة / فائتة (بعد 24 ساعة).
- **Bluetooth (HC-05)** للتحكم والمتابعة من التطبيق.
- **إشعارات** على الموبايل وقت كل جرعة (رقم الجرعة، رقم الصندوق، الوقت).
- الإعدادات بتتحفظ ومبتضيعش عند فصل الكهرباء.

## القطع المستخدمة

| القطعة | الكمية |
|---|---|
| Arduino Mega 2560 | 1 |
| Servo motor | 4 |
| RTC DS1302 (مع بطارية CR2032) | 1 |
| LCD 16x2 I2C (عنوان 0x27) | 1 |
| HC-05 Bluetooth | 1 |
| Push buttons | 5 |
| LEDs | 6 |
| Buzzer | 1 |

## التوصيل (Pins)

| الوظيفة | Pins |
|---|---|
| Servos (الخانات 1-4) | 3, 5, 6, 9 |
| أزرار التأكيد (1-4) | 2, 4, 7, 8 |
| LEDs الجرعات (1-4) | A0, A1, A2, A3 |
| Buzzer | 10 |
| LEDs الحالة | 11, 13 |
| زر الإعدادات | 12 |
| RTC DS1302 (DAT / CLK / RST) | 22 / 23 / 24 |
| LCD I2C (SDA / SCL) | 20 / 21 |
| HC-05 (Serial1) | TX1 = 18، RX1 = 19 |

وصلة HC-05:

- `HC-05 TX` ← `RX1 (19)`
- `HC-05 RX` ← `TX1 (18)` **عن طريق مقسم جهد** (مقاومتين) لأن الـ Mega بيطلع 5 فولت والـ HC-05 بيستحمل 3.3 فولت على خط RX.
- بما إن الـ HC-05 على `Serial1`، مش لازم تفصله وقت رفع الكود.

## المكتبات المطلوبة

- `LiquidCrystal_I2C`
- `Servo`, `Wire`, `EEPROM` (جاهزة مع Arduino IDE)

## الإعدادات من الأزرار

اضغط زر الإعدادات (pin 12) لدخول الوضع، ثم:

- **B1**: رجوع للحقل السابق
- **B2**: زيادة (+)
- **B3**: نقصان (-)
- **B4**: الحقل التالي (وفي آخر حقل يحفظ ويخرج)

## أوامر Bluetooth

الإعدادات: 9600 baud، كل أمر في سطر منتهي بـ `\n`.

| الأمر | الوظيفة |
|---|---|
| `STATUS?` | حالة الصندوق |
| `HISTORY?` | سجل آخر 7 أيام |
| `SETCOUNT,n` | عدد الجرعات (1-4) |
| `SETTIME,index,hour,minute` | ضبط ميعاد جرعة |
| `CONFIRM,index` | تأكيد أخذ جرعة |
| `HELP` | قائمة الأوامر |

الردود: `STATUS,...` / `EVENT,DUE|TAKEN|MISSED,n` / `HISTORY,...` / `OK,...` / `ERR,...`

## تشغيل الأردوينو

1. ثبّت المكتبات من Library Manager.
2. افتح `Medicine-Box.ino` في Arduino IDE.
3. اختار اللوحة **Arduino Mega or Mega 2560** والبورت وارفع الكود.
4. اقرن الـ HC-05 مع الموبايل (الباسورد الافتراضي غالبًا `1234`).

> ⏰ ساعة الـ DS1302 بتتظبط على وقت تجميع الكود في أول تشغيل بس (أو لو فقدت الوقت). تأكد من تركيب بطارية CR2032 عشان الوقت ميرجعش بعد فصل الكهرباء.

## تطبيق الأندرويد

التطبيق مكتوب بـ Kotlin وJetpack Compose، وبيتبني تلقائيًا بـ GitHub Actions:

- الكود في `src/main`.
- كل ما تعمل Commit على `main`، GitHub بيبني ملف `MedicineBox.apk` ويرفعه في تاب **Releases**.
- التطبيق بيتصل بالـ HC-05 (Bluetooth Classic)، ويعرض الجرعات ويعدّل المواعيد ويعرض السجل، ويبعت إشعار وقت كل جرعة.
